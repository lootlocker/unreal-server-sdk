Detailed Description

A single item instance in a player's inventory.

Note: The backend list endpoint returns the raw inventory rows, which currently marshal in PascalCase (the backend Inventory struct is missing JSON tags), whereas the get-item endpoint returns snake_case. The DTO below mirrors the snake_case shape used by get-item, and ListPlayerInventoryItems normalizes the PascalCase keys so both endpoints deserialize correctly. Once the backend adds JSON tags the normalization becomes a no-op.

Note: This represents an item granted from an item template. It is unrelated to FLootLockerServerPlayerInventoryItem, which represents an asset in the player's inventory, and to the asset-based inventory API (GetPlayerInventory, GetUniversalInventory, ...).
